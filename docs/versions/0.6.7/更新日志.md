## 变更明细

### T22-1 patterns.rs `\b` 边界修复 + builtin 补 extract 规则（P0）

#### 用户诉求

1. 提取手机号失败（核心 bug）
2. 规则里需要添加数据提取：身份证号、手机号、姓名（中文）

#### 根因

`crates/core/src/rules/patterns.rs` PHONE.extract = `r"\b\d{11}\b"`。
`regex` crate 1.13.1 默认 Unicode-aware，`\b` word boundary 把中文字符当 word char，
导致 `联系13812345678打电话` 中无 `\b` 边界 → `find_iter` 召回不到候选 → 提取失败。

影响范围：phone / idcard / bankcard / mac 四个 extract 正则都用了 `\b`。
（IP.extract 虽用 `\b`，但 IPv4 四段必含 `.`（非 word char），中文旁也能形成边界，故未改。）

#### 设计决策

- **修复方式**：所有含 `\b` 的 extract 正则加 `(?-u)` 内联标记切到 ASCII 模式。
  regex crate 支持 `(?-u)`，ASCII 模式下 `\b` 在 byte 边界判断，中文旁也能召回。
  实测 `(?-u)\b\d{11}\b` 在 `联系13812345678打电话` 中正确召回 `13812345678`。
- **NAME 限长**：`NAME.extract` 从 `[\x{4e00}-\x{9fa5}]{2,}` 改为 `{2,4}`，
  降低「联系电话」「身份证号」等长中文段误报率（用户决策：限长 2-4 字）。
- **补 extract 规则**：builtin_ruleset 新增 `idcard_extract_rule` + `name_extract_rule`，
  覆盖用户诉求的「身份证号 + 手机号 + 姓名（中文）」三类。
- **不改 IP.extract**：避免超范围。
- **look-around 不可用**：曾试 `(?<!\d)\d{11}(?!\d)` 失败
  （"look-around, including look-ahead and look-behind, is not supported"），故用 `(?-u)\b`。

#### `crates/core/src/rules/patterns.rs`

| 行 | 改前 | 改后 |

### T22-2 ExtractView 提取/校验规则分离（P0）

#### 用户诉求

数据提取的规则不要和数据校验的规则共用，请分开（澄清：指数据提取界面不应有数据校验规则）。

#### 设计决策

- **前端过滤分离**：ExtractView 的 `filteredRules` 锁定 `tag === "extract"`，
  ValidateView 已有 `isValidateRule` 过滤（tag="validate"）无需改，
  RulesView 仍展示全部规则（规则管理视图本职）。
- **tag Select 选项**：保留 Select 但 options 只列 `["extract"]` + 「全部提取规则」，
  避免用户选 validate 后看不到规则。
- **计数 Tag**：Card title 的 `n / total` 由 `rules.validators.length` 改为
  `filteredRules.length`（反映 extract 子集数量）。

#### `frontend/src/components/ExtractView.jsx`

- `filteredRules`：先 `all.filter((r) => r.tag === "extract")` 取 extract 子集，
  再按 `extractRuleTagFilter` 二次过滤（实际 options 已锁 extract，二次过滤几乎无效）。
- tag Select options：`[{label:"全部提取规则",value:"__all__"}, ...tagOptions.filter(t==="extract")]`。
- Card title 计数：`{extractSelectedIndices.length} / {filteredRules.length}`。
- Empty 描述：`(rules.validators?.length || 0) === 0 ? "规则池为空..." : "无带「extract」标签的提取规则"`。

#### `frontend/src/components/ValidateView.jsx`（不动）

`isValidateRule(r) = r.tag === "validate"`，`taggedValidators` 已 filter（line 30-32, 78-80）。
