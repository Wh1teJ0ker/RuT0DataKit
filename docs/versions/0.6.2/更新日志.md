## 变更明细

### T17-1 Core 添加 regex 内置校验规则（P0）

- `crates/core/src/rules/builtin.rs`：新增 `regex_validate_rule()` 函数，返回 `FieldRule { field: "自定义正则", scope: "regex", tag: "validate", params: None, message: None, description: Some("正则校验（自定义 pattern）") }`。加入 `builtin_ruleset()` 的 validators vec（7 → 8）。
- `crates/core/src/rules/mod.rs`：`pub use builtin::{...}` 行追加 `regex_validate_rule`。
- 测试：更新 `builtin_ruleset_has_three_extract_rules`（`validators.len()` 7→8 + regex 断言）；新增 `regex_validate_rule_fields`（字段断言）+ `regex_validate_rule_with_pattern_builds_and_validates`（构造带 `params.pattern` 的规则，`ValidateOp::from_rule` → `apply_validate_op`，验证合法/非法两路径）。

### T17-2 Tauri 添加 trial_validate 命令（P0）

- `src-tauri/src/commands/validate.rs`：新增 `trial_validate(scope, params_json, sample_value) -> Result<Value, String>` 命令。镜像 `trial_mask` 的 params_json 解析逻辑（`HashMap<String, serde_yml::Value>`），构造合成 `FieldRule { field: "", scope, tag: "validate", params, message: None, description: None }`，调 `ValidateOp::from_rule` → `apply_validate_op`，返回 `{ ok, valid, message, error }`。
- `src-tauri/src/main.rs`：`generate_handler!` 宏中 `commands::trial_mask` 后追加 `commands::trial_validate`。
- 修复 `json!` 宏 `null` → `Value::Null` 编译错误（Rust `json!` 宏不像 serde_json::json 那样有 `null` 在 scope）。

### T17-3 Frontend RulesView 校验参数表单 + 试运行 + 应用（P0）

- `frontend/src/tauri.js`：新增 `trialValidate(scope, paramsJson, sampleValue)` 导出，invoke `"trial_validate"`。
- `frontend/src/components/RulesView.jsx`：
  - 新增 `VALIDATE_PARAM_META = { regex: [pattern/message/empty_message] }`，与 `MASK_PARAM_META` 对称。
  - 新增 `getParamMeta(scope)` 辅助函数：先查 `MASK_PARAM_META[scope]`，再查 `VALIDATE_PARAM_META[scope]`，否则 `[]`。
  - `buildParams`：用 `getParamMeta(scope)` 替换 `MASK_PARAM_META[scope]`。
  - `RowExpanded`：有参数元信息就渲染参数表单（不再只看 `isMaskRow`）；结果区 mask 显示 `result.masked`，validate 显示 `result.valid`（合法 ✓ / 非法 ✗ + message）；应用按钮文案随规则类型变化（mask = "应用并跳转数据脱敏"，validate = "应用并跳转数据校验"）。
  - 新增 `runValidateTrialForRow(record)`：调 `trialValidate`，设 result。
  - 新增 `applyValidateForRow(record)`：dispatch `SET_VALIDATE_OVERRIDE` + 跳转 "validate" 视图。
  - `expandedRowRender`：按 `record.__kind` 传 `onRun`/`onApply`（mask → `runTrialForRow`/`applyForRow`，validate → `runValidateTrialForRow`/`applyValidateForRow`）。
  - 操作列：有 `getParamMeta(r.scope).length > 0` 时显示运行+应用按钮（不再只看 `isMaskRow`）。
  - 底部提示文本追加："校验模版填写 pattern 后试运行验证正则，应用后写入数据校验视图"。
