# v0.1.0 规划需求

## 范围

数据脱敏切片：CSV/Xlsx reader + 脱敏 pipeline + masked.csv 导出 + Tauri GUI 入口 + 内置脱敏规则。
同时落地 v0.1.1/v0.1.2 复用的共享底座（注册表 / Reader trait / SensitiveScan trait / Report schema / CoreError.DependencyMissing），避免后续大重构。

v0.1.0 重构增量（侧边栏 + 富规则 + 行选择）：
- GUI 改为侧边栏布局，首项「文件处理」激活；日志扫描 / 流量分析置灰占位。
- 「文件处理」视图：导入 CSV/XLSX → 预览表格 → 每行勾选框（表头不可勾选）→ 规则面板（添加/删除规则）→ 应用规则到勾选行 → 导出 CSV。
- 新增 4 种富规则 masker：`regex_replace` / `regex_extract` / `delete` / `replace`。
- 新增 `mask_pipeline_selected` 行选择 pipeline：只对勾选行脱敏，未选中行原样。
- 规则可由 GUI 直接编辑后以 JSON 传后端，不再强制走 YAML 文件。

详见 `docs/00-需求文档.md` §3 与 §7。

## 范围突破（2026-07-19）

用户反馈要求把导航改为四功能 + 按列勾选 + 规则详细说明与编辑 + 脱敏/校验数据可跳转导出 + 跨视图 state 不丢，v0.1.0 重开为「四功能重构补丁」（任务 T0-15 ~ T0-20）。范围突破项：

- **四功能导航**：侧边栏 4 active view（数据脱敏 / 数据校验 / 数据导出 / 规则管理）+ 2 disabled（日志 v0.1.1 / 流量 v0.1.2）；原「文件处理」单视图拆分为四 view。
- **按列勾选脱敏**：新增 `mask_pipeline_columns(records, rules, selected_columns: &HashSet<String>)`；MaskView 表头列 checkbox + 「应用规则到勾选列」按钮。
- **数据校验 GUI**：新增 `validate_pipeline(records, rules) -> ValidateResult { headers, rows, valid_matrix, summary }`；ValidateView 独立交付，含「运行校验」+「跳转到数据导出」。
- **数据导出列选/列序/格式**：ExportView 选数据源（原始/脱敏/校验）+ 列勾选 + 列序拖拽 + 格式（CSV / XLSX）；XLSX 由 src-tauri `rust_xlsxwriter` 写出，CSV 由 src-tauri `csv` crate 写出。
- **规则详细说明 + 编辑 + YAML 存取**：`MaskRule` / `FieldRule` 加 `description: Option<String>`（`#[serde(default)]`）；RulesView 含编辑表单（RuleForm editMode）+ 「保存 YAML」/「加载 YAML」/「查看规则说明」（RuleDocPanel）；前端 `js-yaml@5.2.1` 负责 YAML 序列化。
- **跨视图 state 持久化**：`App.jsx` 顶层 `useReducer` 内存常驻，`SET_VIEW` 只切 view 不重置数据；切回各 view 数据不丢。
- 向后兼容：旧 `mask_pipeline` / `mask_pipeline_selected` 与 7 个旧 src-tauri 命令保留不动。

## 目标

- 读 csv / xlsx → 加载 default_mask 规则 → 输出 masked.csv。
- 内置 maskers 覆盖 spec.pdf 全部脱敏规则；另提供 4 种富规则 masker。
- GUI：**侧边栏布局**，「文件处理」视图支持 导入 → 预览 → 行勾选 → 规则编辑（含富规则）→ 应用到勾选行 → 导出。
- pcap/log 入口在 GUI 置灰，标注"v0.1.2 / v0.1.1 提供"，文案与禁用逻辑提前到位。

## 不做（v0.1.0）

- 磁盘取证 / 盲水印 / ext4。
- xlsx 写回公式。
- CLI 入口（仅交付 GUI，不提供 CLI）。
- pcap / log 实际实现。

> 「校验 pipeline 的 GUI 入口」与「按行勾选」两条原「不做」条款已于 2026-07-19 范围突破时移除：v0.1.0 起交付校验 GUI 独立 view（ValidateView）；脱敏入口由行勾选改为列勾选（行勾选 pipeline `mask_pipeline_selected` 仍保留向后兼容）。
