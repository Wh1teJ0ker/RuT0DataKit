# v0.2.3 规划需求

## 范围

日志扫描盲注切片的「显示结果 + 代码 + 类型」三轴优化补丁：在 v0.2.2 跨 entry 布尔盲注
二分序列聚合还原的基础上，对（a）`blind_aggregator` 算法与正则、（b）支持的盲注类型、
（c）GUI 聚合结果卡片三轴做优化，并补齐 v0.2.2 遗留的 `true_size` 方向误判隐患。

## 目标

- **算法优化（T3-1）**：
  - 把 v0.2.2 的 `true_size = min(body_size)`（fixture-specific 假设，反向场景会误判）
    改为 `mode_per_position_true_size`：按 `char_position` 分组 → 每个「混合位置」取真假
    两簇 `body_size` 中较小者（fixture：true 簇 body 更小）/ 较大者（反向场景：true 簇
    body 更大）作为该位置 true_size → 跨位置众数（并列取较小者）→ 无混合位置时退化为
    `min(body_size)`。fixture 第 4 read_target（false 频次高于 true）也能正确解出。
  - 自带正则从单层嵌套扩展到两层：`((?:[^()]|\((?:[^()]|\([^()]*\))*\))*)` 吃掉
    `where table_schema=database()` 这类两层 `(...)`。
  - `AggregatedResult` 新增 `separator_char: Option<char>`：从 `read_target` 首个
    `0x([0-9a-fA-F]{2})` 字面量解码出分隔符（如 `0x7e` → `~`），`0xff+` 返回 `None`。
- **盲注类型扩展（T3-2）**：
  - `BlindProbe` 新增 `probe_kind: ProbeKind` 枚举（`AsciiBinary` / `Equality` / `Length`）+
    `equality_char: Option<char>`。
  - 新增 2 条正则：
    - equality：`substr((<read_target>),N,1)=('x'|char(NN))` → 直接解出单字符。
    - length：`length((<read_target>))(>=?|<=?|=)(\d+)` → 解出目标字符串长度。
  - 聚合分组键由 `(read_target, source_ip)` 升级为 `(read_target, source_ip, ProbeKind)`
    三元组，同一 read_target 的不同探针类型互不污染（避免 ascii_binary 与 length 串扰）。
  - `AggregatedResult` 新增 `kind: Option<String>`（序列化为 `ascii_binary` / `equality` /
    `length`，`#[serde(skip_serializing_if)]` 缺省时不出现）。
  - `PositionDetail.status` 新增 `equality_resolved` / `length_resolved` 两个分支。
- **GUI 显示优化（T3-3）**：
  - 段 ③.5 inner Card：extra = 探针类型 Tag（`kind` 着色：ascii_binary=red / equality=orange
    / length=blue；`r.kind` 缺失时前端按 `position_details[0].status` 兜底推断）+ 已解 N/M Tag。
  - 还原结果：`separator_char` 存在 → `Text strong` + volcano Tag 包裹分隔符高亮分段 + 独立
    「复制」按钮（`navigator.clipboard.writeText`）；否则 `Text strong copyable` 原样。
  - 位置明细由 v0.2.2 的 Tooltip + JSON.stringify 升级为 antd `Collapse` + 内嵌 `Table`：
    列 位置 / 字符 / ASCII / 探针数 / 状态（status Tag 着色 6 色），默认折叠。
- **收尾（T3-4）**：版本号 0.2.2 → 0.2.3（5 文件）；文档同步；Phase 7 端到端验收；
  Release QA 报告 `docs/qa/versions/0.2.3/QA-审计报告.md` 结论 `qa_passed`；
  git commit + tag v0.2.3 + push GitHub（SSH）；清理 `handoff/`。
