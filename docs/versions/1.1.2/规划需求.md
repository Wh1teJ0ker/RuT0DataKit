# v1.1.2 规划需求

> 前置：v1.1.1 已 `qa_passed` 并发布 tag `v1.1.1`（撤销/重做 + 列操作 JSON 解析 + 搜索 + commands 层测试）
> 范围：v1.1.2 — Base64 列编解码 + 设置界面优化 + 设置按钮移位 + tshark 测试加固 + .log 导入支持

## 一、版本目标

v1.1.2 在 v1.1.1 之上交付五项增量：

1. **列操作 — Base64 编解码**：对某列做 Base64 编码或解码（就地变更，可撤销）
2. **设置界面文案精简**：移除 DbPathCard / AboutCard / TsharkPathCard 中冗余描述
3. **设置按钮移至右上角**：从 AiPanel 底部迁移到 TopToolbar 右端
4. **tshark 解析测试加固**：验证 Windows 路径候选 + 集成测试覆盖现有 fixture
5. **.log 文件导入**：新增 LogReader，按行解析导入

## 二、明确不做（推迟）

- 非 Base64 的加密算法（AES/RSA 等）
- .log 文件的结构化字段解析（仅按行导入为单列文本）
- tshark 非 HTTP 协议解析（DNS/TCP 等仍推迟）
- DbPathCard 的动态 DB 路径命令（仍保持硬编码展示）

## 三、验收标准

- `cargo fmt --check` + `cargo clippy --workspace -- -D warnings` + `cargo test --workspace` 全绿
- `pnpm --prefix frontend build` 通过
- Base64 编码 → 列值变 Base64；解码 → 恢复原文；撤销可恢复
- 设置按钮在 TopToolbar 右端可见且可点击进入设置页
- 设置页文案无冗余描述
- .log 文件可通过导入对话框选择并成功导入
- tshark 测试覆盖 Windows 路径候选 + fixture 集成测试（本机有 tshark 时）
- 版本号 6 处一致 1.1.2
