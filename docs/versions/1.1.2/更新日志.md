## 关键设计决策

- **Base64 列编解码用闭包式 DB 方法**：`base64_transform_column_cells<F>` 接受 `Fn(&str) -> Option<String>` 闭包，使 DB 层不依赖 commands 层的 `Base64Mode` 枚举；转换逻辑（`base64` crate 编/解码）由 commands 层在闭包内实现，DB 层只提供事务 + before/after 快照机制。职责清晰，DB 层可被其他转换类操作复用。
- **.log 导入格式自动识别 + 结构化解析**：`LogReader` 在 `read_all()` / `headers()` 内对前 10 条非空行做 probe，按正则命中数选最匹配格式。支持四格式 + 未识别回退单列：Apache Combined（11 列 + raw_line，`request` 拆 method/url/protocol，`body_bytes_sent` 为 `-` 时归零）/ Apache Common（9 列 + raw_line）/ Syslog RFC 3164（5 列 + raw_line，pid 可选）/ 通用应用日志（4 列 + raw_line，thread 可选）/ fallback 单列 `line`。正则经 `std::sync::OnceLock` 缓存，`raw_line` 始终保留原始全文，解析失败的行各字段留空、`raw_line` 保留原文。复用 `Reader` trait + `detect_format` 工厂分发，符合 §2.5 扩展路径。改动仅限 `crates/core/src/datasource/log.rs`，不触动 processor / db / table 模块（`import_file` 已按 `headers()` 驱动列结构）。
- **设置按钮迁移不改路由**：仅把入口从 AiPanel 底部迁到 TopToolbar 右端（`flex:1` 占位推到最右），`onClick` 仍调 `setView("settings")`，`App.jsx` 路由逻辑不变。
- **Base64 抽离为独立加解密面板**：v1.1.2 把 Base64 编解码 UI 从 `ColumnOpsPanel` 迁至新建 `CryptoPanel`，在 TopToolbar `CAPABILITIES` 数组新增 `crypto` 能力按钮（`KeyOutlined` 图标），走 `activeCapability` XOR 切换 + 260px `SidePanel` 注册表，与脱敏/校验/提取/列操作一致。`ColumnOpsPanel` 仅剩 JSON 解析。`CryptoPanel` 作为后续所有加解密/哈希/编解码类操作的统一入口（v1.1.2 承载 Base64，预留扩展位）。纯前端 UI 重组，`base64_column` IPC / DB 方法 / Rust 命令不变。
- **全局每页行数持久化沿用 settings.json**：扩展 `TsharkSettings` → `AppSettings`，新增 `#[serde(default)] page_size: Option<u32>`，与 tshark 路径同文件同模式；旧 settings.json 无此字段反序列化时取 `None`，前端回退 `PAGE_SIZE=50`。前端 `SET_PAGE_SIZE` reducer 同时更新全局 `state.pageSize` 与所有 `sheet.pageSize`（page 重置 1，避免页码越界），`PageSizeCard` 保存后只 dispatch 一次 + 刷新当前激活 Sheet 首页。`toRowObjects` 的 `_rowIdx` 计算从硬编码 `PAGE_SIZE` 改为接收 `pageSize` 参数，保证切换行数后行号正确。`PAGE_SIZE` 常量保留作为编译期兜底默认值。
- **schema 不变**：v1.1.2 无新增表/列/索引，`SCHEMA_VERSION=3` 保持；`operations.kind="base64_column"` 复用 v1.1.1 已加的 `before_snapshot_json`/`result_snapshot_json` 列，从 v1.1.1 升级无需迁移。

## 已知边界

- Base64 仅支持标准 `STANDARD` engine，不支持 URL-safe / no-padding 变体（推迟 v1.2+）
- `.log` 结构化解析覆盖四种主流格式（Apache Combined/Common、Syslog、通用应用日志），非主流格式回退单列 `line`；正则匹配基于行级 probe，不处理跨行多行日志（推迟 v1.2+）
- tshark 集成仅覆盖 HTTP 协议（DNS/TCP 推迟 v1.3+）；本机无 tshark 时相关测试 `#[ignore]` 跳过
- DbPathCard 仍硬编码 DB 路径展示（动态命令推迟 v1.2+）
