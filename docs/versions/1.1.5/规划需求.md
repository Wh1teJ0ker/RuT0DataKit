# v1.1.5 规划需求 — 校验增强 + 列操作扩展 + 脱敏选项

> 版本：`1.1.5`（PATCH — 同一 minor 内的能力增量与缺陷修复）
> 状态：`in_progress`
> 开始日期：2026-08-13

## 1. 背景与范围

v1.1.4 完成校验模块统一（ExtractParams + 6 条 validate 规则 + 行级多字段校验 +
Generic 校验 + 手机号前缀 UX + 规则排序）。v1.1.5 在此基础上做 6 项面向用户的能力增强：

1. **邮箱校验规则** — 新增 `email-validate` 函数式校验规则
2. **.db 文件导入前端修复** — 文件选择器 extensions 数组追加 `db` / `sqlite` / `sqlite3`
3. **哈希输出大小写 hex** — `hash_column` 新增 `case` 参数（`lower` / `upper`）
4. **先校验再脱敏** — `mask_column` 可选先校验，不通过则输出 INVALID（可自定义）
5. **列操作大小写归一化** — `transform_column` 命令 + ColumnOpsPanel UI
6. **生日校验多格式可选** — `ExtractParams::Birth` 支持 `formats` 字段，前端可勾选
