## 变更摘要

### 新增

- **邮箱校验规则**（T81）：`ExtractParams::Email` 变体 + `is_valid_email` 函数式校验 + `email-validate` 规则播种（with_defaults 17→18）
- **.db 导入前端修复**（T82）：TopToolbar 文件选择器 extensions 追加 `db` / `sqlite` / `sqlite3`
- **哈希大小写 hex**（T83）：`HashCase` enum（lower/upper）+ `hash_column` case 参数 + CryptoPanel Radio.Group
- **先校验再脱敏**（T84/T85）：`mask_column` 追加 `validate_rule_id` / `invalid_text` / `params_override` / `phone_prefixes` 可选参数 + MaskPanel Checkbox + 校验规则 Select
- **列操作大小写归一化**（T86）：`transform_column` 命令（复用 `base64_transform_column_cells` 闭包）+ ColumnOpsPanel 新增列变换区块
- **生日多格式可选**（T87/T88）：`ExtractParams::Birth` 改为 struct variant（`formats: Vec<String>`，空=全部接受）+ `is_valid_birth_format` + ValidatePanel 格式勾选

### 向后兼容

- `hash_column` 的 `case` 参数前端默认传 `lower`，后端不变更既有测试向量
- `mask_column` 的新参数全部 `Option`，`validate_rule_id=None` → 原有行为
- `ExtractParams::Birth` serde `#[serde(default)]` formats → `{"validator":"birth"}` 仍可反序列化
- `.db` 导入后端在 v1.1.4 T75 已完整实现，本次仅修前端过滤
