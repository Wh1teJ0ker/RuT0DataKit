# v0.4.0 更新日志

> 架构性完整重构：从「按数据源分片」演进为「按功能分界面（7 个主界面）」的统一架构。
> 所有数据源（csv/xlsx/sql/pcap/log/json）统一进入数据预处理界面归一化为 `Records`，后续功能界面共享预处理产物。

## 版本范围

7 个主界面：
1. 数据预处理（csv/xlsx/sql/pcap/log/json → 统一 Records 表格 + 跳转）
2. 规则管理（规则引擎重构 + 多标签适配所有功能）
3. 搜索（关键词 + 正则 + 倒排索引）
4. 数据脱敏（复用四段垂直布局，消费预处理产物）
5. 数据校验（同四）
6. 数据导出（xlsx/csv/json 三格式）
7. Tools（SQL 解析全盲注类型 + 数据库还原；正则解析 + 辅助写正则）

`release_complete` — 全部任务 `verified_complete` + 端到端集成验收通过 + Release QA 审计 `qa_passed` + 版本文档同步完成。

## 端到端验收项

- 6 源预处理：csv/xlsx/sql/pcap/log/json 各导入一张表，PreprocessView 预览 headers/rows 一致。
- 7 界面全 active 无 disabled。
- 规则多标签：一条规则挂 mask+sensitive 双标签，RulesView/MaskView 都能选到。
- 搜索：≥10w 行 fixture 倒排索引构建 < 5s，单次查询 < 200ms。
- 数据脱敏/校验/导出数据源切换不丢数据。
- 数据导出 json 格式行数 = 原始行数，key = headers。
- Tools SQL 解析：v0.2.4 fixture 探针序列还原出 schema=person / 1 表 person_data / 7 列。
- Tools 正则解析：`^1[3-9]\d{9}$` 解释正确；邮箱模板生成可跑通。
- `cargo test --workspace` 全绿；npm build；tauri build 产出 v0.4.0 dmg。
