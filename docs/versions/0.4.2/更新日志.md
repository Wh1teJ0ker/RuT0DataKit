# v0.4.2 更新日志

> 设置模块首期：Sidebar 底部「设置」入口 + tshark 多平台自动检测 + 路径配置持久化 + SettingsView UI；附带 v0.4.1 搜索子串匹配缺陷修正。

## 版本范围

4 项（3 主任务 + 1 附带修正）：

1. **tshark 多平台自动检测**（T7-1）：core 新增 `pcap/detect.rs`，进程级全局覆盖路径 + `detect_tshark` 多平台候选探测；`PcapReader::read` 注入覆盖路径（None 时零回归）。
2. **Tauri 命令 + settings.json 持久化**（T7-2）：`detect_tshark` / `load_tshark_path` / `save_tshark_path` 三命令 + `app_config_dir/settings.json` 持久化 + 运行时注入；版本号 0.4.1 → 0.4.2。
3. **Sidebar 底部「设置」按钮 + SettingsView UI**（T7-3）：Sidebar `flex:1` + 贴底 Button + 状态 Tag；SettingsView Card + Descriptions + 4 操作按钮 + 平台路径 Alert；挂载自动探测。
4. **附带搜索子串匹配修正**（T7 附带）：`search_keyword` 精确匹配 → 子串匹配 `key.contains(term)`，搜「张」命中「张三」；新增 CJK + ASCII 子串测试。

**v0.4.2 patch 修复（3 项，版本号不变，T8-1 / T8-2 / T8-3）**：

5. **修复 A — 文件导入对话框缺 json/sql 扩展名**（T8-2）：`src-tauri/src/commands.rs:87` `select_file` 的 `add_filter` 扩展名补齐 `.sql` / `.json`，6 类源（csv/xlsx/sql/json/log/pcap）均可在对话框被选中。
6. **修复 B — 侧边栏与主页面一起滚动**（T8-2）：`frontend/src/App.jsx` 外层 `<Layout>` 锁 `height: 100vh, overflow: hidden`，`<Sider>` 改 `position: sticky, top: 0` 固定，`<Content>` 加 `overflowY: auto`；修复后侧边栏固定不动、主内容独立滚动。
7. **修复 C — 脱敏/校验下拉显示算子模板而非用户规则**（T8-2）：`MaskView.jsx` / `ValidateView.jsx` 下拉源由 `listMaskOpTypes` / `listValidateOpTypes` 算子模板清单改为 `state.rules.maskers` / `state.rules.validators` 按 tag 筛选后的用户规则子集；下拉项 value=规则下标、label=`field → masker(params=...)`；选中规则即整条作为 override 写入；删除「参数」列、新增「规则摘要」列；无规则时 `Alert` 引导去 RulesView。
