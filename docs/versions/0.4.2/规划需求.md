# v0.4.2 规划需求

## 范围

**设置模块首期**：在 Sidebar 导航栏最底部新增「设置」跳转按钮，首期唯一功能是**自动针对多平台（macOS / Windows / Linux）找到 tshark 程序，并允许用户配置/保存自定义路径**。配置后 pcap 解析（`PcapReader::read`）使用配置的路径而非硬编码 `tshark`，解决「tshark 装在非 PATH 路径（如 Wireshark.app 内）时 pcap 解析失败」的痛点。

附带修正：v0.4.1 用户反馈的搜索子串匹配缺陷（搜「张三」能搜到，搜「张」搜不到）。

## 用户原始诉求（逐字保留）

1. **v0.4.2 主诉求**：「然后加入一个导航栏最下方加入一个设置的跳转按钮，当前只需要用于自动化针对多平台找到tshark的程序，并且配置路径，这是v0.4.2版本」
2. **v0.4.1 遗留搜索子串缺陷**：「找出问题了，例如张三，能搜到，但是搜张就搜不到」

## 目标

### 1. tshark 多平台自动检测（T7-1）

- core 新增 `crates/core/src/pcap/detect.rs`：进程级全局覆盖路径（`std::sync::Mutex<Option<String>>`）+ `set_tshark_path` / `get_tshark_path` / `resolve_tshark_cmd` / `detect_tshark` / `candidate_paths` / `probe_tshark`。
- `detect_tshark` 按优先级探测：① 当前覆盖路径；② PATH 中的 `tshark`（`Command::new("tshark")`）；③ 各平台候选绝对路径（macOS homebrew / Wireshark.app / Linux `/usr/bin` / Windows Program Files）。每个候选跑 `<path> --version`，退出 0 即视为可用，解析首行作为 version。返回 `TsharkInfo { path, version }`，全部失败返回 `None`。
- `PcapReader::read` 两处 `Command::new("tshark")` 改为 `Command::new(&resolve_tshark_cmd())`。覆盖为 None 时等价于原 `tshark` 字面量，行为与 v0.4.1 完全一致（零回归）。
- 单测：候选路径过滤逻辑 + set/get roundtrip + resolve_falls_back + probe_nonexistent + `#[ignore] detect_local`。

### 2. Tauri 命令 + settings.json 持久化（T7-2）

- 新增 3 个命令（同步 `Result<_, String>` 风格，无新 Cargo 依赖）：
  - `detect_tshark() -> Result<Value, String>`：调 core `detect_tshark()`，返回 `{ path, version }` 或 `{ path: null, version: null }`。
  - `load_tshark_path(app: AppHandle) -> Result<Option<String>, String>`：读 `app_config_dir/settings.json` 的 `tshark_path`；同时 `set_tshark_path` 注入 core 运行时。
  - `save_tshark_path(app: AppHandle, path: Option<String>) -> Result<(), String>`：`create_dir_all` + `serde_json::to_string_pretty` + `std::fs::write` + `set_tshark_path` 注入。
- settings.json 结构：`{ "tshark_path": "/opt/homebrew/bin/tshark" }`（仅此一字段，未来可扩展）。
- `main.rs` `generate_handler![]` 末尾追加三个命令。
- 版本号 0.4.1 → 0.4.2（`src-tauri/Cargo.toml` + `tauri.conf.json`）。

### 3. Sidebar 底部「设置」按钮 + SettingsView（T7-3）

- `Sidebar.jsx`：Menu 加 `flex: 1` 占满中段；Menu 下方加带 `borderTop` 分隔线的 div + antd `<Button block icon={<SlidersOutlined />}>设置</Button>`（`type` 随 `activeView === "settings"` 切 `primary` / `text`），按钮内嵌状态 `Tag`（绿「tshark ✓」/ 红「tshark ✗」/ 无）。
- `state.js`：新增 `tsharkPath` / `tsharkDetected` / `tsharkLoading` + 三 reducer case。
- `tauri.js`：新增 3 个 camelCase 封装 `detectTshark` / `loadTsharkPath` / `saveTsharkPath`。
- `App.jsx`：import `SettingsView` + `view === "settings"` 路由分支。
- `SettingsView.jsx`（NEW）：Card + Descriptions 3 列（状态 Tag / 检测路径 / 版本号）+ Space 4 按钮（自动检测 / 使用检测到的路径 / 选择文件… / 清除自定义路径）+ Alert 平台路径参考。挂载 `useEffect` 自动 `loadTsharkPath` + `detectTshark`；失败不阻塞。

### 4. 附带搜索子串匹配修正（T7 附带）

- 根因：`tokenize` 用 `char::is_alphanumeric` 把连续中文聚成单 token（如「张三」是一个 postings key），原 `search_keyword` 精确匹配 `index.postings.get(t)` 漏掉部分中文查询。
- 修复：改为子串匹配，对每个 term 扫所有 postings key，`key.contains(term.as_str())` 即命中。搜「张」命中 `张三` / `张三丰`；ASCII 场景同样受益（搜「ali」命中 `alice`）。
- 新增 2 单测：`keyword_substring_matches_cjk_partial` / `keyword_substring_matches_ascii_partial`。
