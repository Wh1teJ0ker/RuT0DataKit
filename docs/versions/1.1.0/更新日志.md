# v1.1.0 更新日志

> 版本：1.1.0
> 主题：数据处理原型三件套（脱敏 / 校验 / 提取）+ 规则管理基础结构（3 条姓名规则 + DB 持久化）
> 状态：`verified_complete`（cargo fmt/clippy/check/test 全绿 + pnpm build 通过）
> 公开 Release：暂无（待 QA 推进）

## 版本摘要

v1.1.0 在 v1.0.0 纯框架 shell 之上，落地**数据处理原型三件套**——脱敏 / 校验 / 提取——以及**规则管理基础结构**。core crate 新增 `processor` 模块（纯逻辑引擎，`regex` crate 纯 Rust 无 native 依赖），定义 `Masker` / `Validator` / `Extractor` trait 与原型实现，以及 `Rule` / `RuleKind` / `RuleRegistry` 规则管理结构。内置**三条姓名相关规则**（脱敏 / 校验 / 提取各一）。规则**持久化到 SQLite**（`rules` 表，`SCHEMA_VERSION=2`，v1→v2 增量迁移），应用重启后规则与参数保留。Tauri 命令层新增 6 个 IPC，前端 4 个能力面板从占位提示升级为真实 UI，支持行状态高亮（`masked` / `invalid` / `hit`）。RulesPanel 改为 Workbench 主区两栏布局（左列表 + 右详情 + 可填参数 + 内联测试），**不提供新增规则能力**。

## 更新内容

### 新增

- **core `processor` 模块**（`crates/core/src/processor/`）：
  - `rules.rs`（`Rule` / `RuleKind` / `RuleRegistry` + 内置 3 条姓名规则：`name-validate` / `name-mask` / `name-extract`；`RuleKind::from_str_lowercase` round-trip）
  - `validator.rs`（`Validator` trait + `RegexValidator`）
  - `masker.rs`（`Masker` trait + `SimpleMasker`：规则带 replacement → 直接替换；规则 kind=Mask replacement=None → 保留首字符 + 其余 `*`；无规则 → 首尾保留）
  - `extractor.rs`（`Extractor` trait + `PiiExtractor`：内置手机 / 邮箱 / 身份证 3 正则）
- **`regex` 依赖**：`crates/core/Cargo.toml` 添加 `regex = "1"`（纯 Rust，无 native 依赖）
- **DB schema 升级 `SCHEMA_VERSION=2`**：新增 `rules` 表（id/name/kind/field/pattern/replacement/enabled/description）+ `idx_rules_kind` 索引；`migrate.rs` 新增 `migrate_v1_to_v2`（`IF NOT EXISTS` 幂等增量迁移，不触发备份重建）；`db/mod.rs` 新增 `query_column_cells` / `find_col_idx` / `upsert_rule` / `list_rules` / `get_rule` / `set_rule_enabled` / `count_rules` / `update_rule_params` / `seed_builtin_rules` / `row_to_rule`
- **6 个 Tauri 命令**（`src-tauri/src/commands/processor.rs`）：
  - `mask_column`（读列 → 从 DB 取 rule → SimpleMasker → 回写 upsert + log_operation）
  - `validate_column`（读列 → 从 DB 取 rule → RegexValidator → 返回 RowValidation[]）
  - `extract_column`（读列 → PiiExtractor → 返回 RowExtract[]）
  - `list_rules`（从 `DbManager::list_rules()` 读全部规则）
  - `toggle_rule`（`DbManager::set_rule_enabled`）
  - `update_rule_params`（`DbManager::update_rule_params`，持久化可填参数 `pattern` / `replacement`）
- **启动 seed**：`lib.rs` setup 中 `DbManager::new` → `seed_builtin_rules()`（DB 为空时写入 3 条内置规则）；删除原 `RuleState(Mutex<RuleRegistry>)` 托管，规则改由 DB 单一真源
- **前端 state**：`ACTION.APPLY_ROW_STATUSES` + reducer case（按 `rowKey` 更新 `row.status` + `statusHighlights`）+ `AppContext.applyRowStatuses` dispatcher + `toRowObjects` 增加 `_rowIdx` 字段（`(page-1)*pageSize + i + 1`，与后端 `rowIdx` 对齐）
- **前端 IPC 封装**：`maskColumn` / `validateColumn` / `extractColumn` / `listRules` / `toggleRule` / `updateRuleParams` 6 个 invoke 封装
- **4 个能力面板升级为真实 UI**：
  - `MaskPanel`：选列 → 执行脱敏 → 回写 DB + 重新拉取当前页 + 行高亮 `masked`
  - `ValidatePanel`：选列 + 选规则（`kind==="validate"`）→ 执行校验 → 不通过行高亮 `invalid`
  - `ExtractPanel`：选列 → 执行提取 → 命中行高亮 `hit` + 底部 PII 列表（kind Tag + 值）
  - `RulesPanel`（Workbench 主区两栏布局）：左侧 240px antd List（规则名 + kind Tag + 启用 Tag）+ 右侧详情 Card（规则信息 + 可填参数 pattern/replacement + Save → `updateRuleParams` 持久化 + 内联测试 TextArea）；**无新增规则入口**
- **路由**：`App.jsx` 按 `activeCapability === "rules"` 渲染 `<RulesPanel/>` 占据 Workbench 主区，其余走原 `<SidePanel/> + <Workbench/>`；`SidePanel` 的 `PANELS` map 删除 `rules` 条目
- **版本号升级**：`1.0.0` → `1.1.0`（Cargo.toml / tauri.conf.json / package.json / constants.js）

### 明确不做（推迟至 v1.2+）

- 撤销栈 / 操作回滚
- **新增规则能力**（v1.1.0 规则集固定为内置 3 条，仅可填参数层级）
- 全局搜索 / Tools / tshark 集成 / PCAP / 真实 AI
