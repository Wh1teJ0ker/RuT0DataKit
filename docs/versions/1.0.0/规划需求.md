# v1.0.0 规划需求

> 本文件为 v1.0.0 版本子文档，范围与任务清单与 [`docs/03-开发任务清单.md`](../../03-开发任务清单.md) 对齐。版本状态口径见 [`docs/04-版本标准.md`](../../04-版本标准.md)。

## 1. 版本定位

v1.0.0 是 RuT0DataKit 从零重写后的首个里程碑，交付**纯框架 shell**：

- 建立四区布局 shell（上方工具栏 / 左侧操作栏 / 中央 Workbench 70% / 右侧 AI 面板占位）。
- 建立以 antd Table 为中心的工作台（Sheet/Tab 多页 + 选区 / 列选 / 列序 / 状态高亮骨架）。
- 建立 SQLite 全量数据持久 + 操作日志，重启可恢复完整数据与历史。
- 集成 Tauri updater 自动检查更新（带 Ed25519 签名）。
- 预留 AI IPC 契约（`ai_suggest` / `invoke_ai_op` 空实现）。
- 提供设置入口（updater 检查 / tshark 路径占位 / DB 路径展示 / 关于）。

v1.0.0 **不实现任何业务能力**：脱敏 / 校验 / 提取 / 规则 / 搜索 / Tools / 日志 / PCAP / 真实 AI 均推迟至 v1.1+。左侧 7 项操作中除「设置」外，点击统一提示「…能力 v1.1+ 释放」。

## 3. 验收标准（v1.0.0 11 项）

1. `cargo check --workspace` 通过，`cargo tauri dev` 可启动。
2. 四区布局可见，占比符合 [`01-页面与交互说明.md`](../../01-页面与交互说明.md) §1。上方工具栏左组 6 项数据操作 + 右组 4 项能力按钮（脱敏/校验/提取/规则管理）可见。
3. 右组能力按钮点击后左侧能力面板切换到对应能力面板（占位提示「v1.1+ 释放」）；左组禁用项点击弹 `v1.1+` 提示；左侧面板底部「⚙ 设置」始终可见，点击进入设置页。
4. 可新建 / 切换 / 关闭 / 重命名 Sheet Tab。
5. antd Table 支持行复选 + 区间选择、列 checkbox 显隐、列拖拽排序。
6. SQLite 5 表 3 索引存在，重复启动不重复建表，`schema_version` 正确。
7. 导入 1000 行 CSV / XLSX：Sheet 新建、Table 渲染首页、分页可翻。
8. 重启应用后通过「打开历史 Session」可重新加载该 Sheet 全量数据。
9. `operations` 表有对应 `import` 记录。
10. `check_update` 无新版本返回 `available=false`；无网络静默降级；签名校验失败拒绝安装。
11. 前端调用 `aiSuggest` 得到 `v1.1+` 错误文案，UI 不崩溃。

## 5. 安全约束

- 全本地处理，数据不外发。
- updater 仅由 Tauri 插件发起 HTTPS 请求拉取版本元数据 + 签名产物，不传用户数据或样本。
- 下载产物必须通过公钥验签，失败拒绝安装。
- 签名密钥通过 GitHub Secret 注入，不落盘仓库。
