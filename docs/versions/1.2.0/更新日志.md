## 最终摘要

v1.2.0 是一个架构升级版本。核心交付：

1. **后端模块拆分**：3 个过大文件拆为 11 个职责子模块（db 5 子模块、commands/processor 4 子模块、core/rules 2 子模块），零编译 warning，167 + 15 doc-tests 全绿。
2. **前端共享抽象**：`useBreakpoint` / `useRules` / `useSheetOps` hooks + `ColumnSelect` / `PhonePrefixSelect` / `TemplateEditor` 共享原语，消除 MaskPanel ↔ RulesPanel 模板编辑器重复。
3. **前端高适应性升级**（T98–T115）：断点感知（`Grid.useBreakpoint()`）驱动全布局响应；SidePanel/AiPanel 可折叠 + 可固定（pinned 时窄屏不自动折叠）；TopToolbar wrap 换行；RulesPanel 自适应堆叠 + overlay 滚动修复；散落硬编码像素宽度收敛为 flex/vh 响应式值；根布局 dvh 兼容。
4. **UI 文案精简**：所有面板描述精简为简洁一句话。
5. **临时文件清理**：删除 `STARTER.md`、旧版 `RELEASE-NOTES.md` / `RELEASE-BODY.md`。
6. **IPC 签名不变**：32 个 `generate_handler!` 命令列表未变，`SCHEMA_VERSION=5` 未变，无新增依赖 crate。
7. **版本号同步**：`tauri.conf.json` / `Cargo.toml`（workspace） / `frontend/package.json` / `APP_VERSION` 全部为 1.2.0。
