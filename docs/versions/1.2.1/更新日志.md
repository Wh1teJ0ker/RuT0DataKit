## 版本主题

三阶段交付：
1. **性能修复**：解决 8.5 MB 单行无换行 TXT 文件导致前端卡顿/冻结的问题。
2. **一致性修复 + 架构优化**：修复手机号规则管理与实际功能数据不一致（空名单误过滤）；
   拆分 4 个 god-file（extract_ops.rs / func_validator.rs / rules/mod.rs / RulesPanel.jsx）；
   提取共享 helper 消除 ~150 行重复；删除 ~850 行死代码。
3. **第三轮架构优化**：Rust 后端表驱动去重 + 正则缓存 + 共享 helper 收敛；
   前端共享 hooks（useActiveSheet/useStaleGuard/useSheetOps）+ AppContext 精简（25 useCallback → dispatch+ACTION）；
   3 个前端 god-file 拆分（DataTable 455→287 / ValidatePanel 412→177 / ExportModal 378→246）；
   常量集中 + 死导出删除；文档漂移修正（func_validator/validate_column/extract_column 引用清零）。
