# v0.5.0 规划需求

> 架构性质升级版本：基于 `docs/qa/代码质量审计报告.md` 的 P0+P1+P2 路线图，解决高内聚 / 低耦合短板，保持行为零回归。

## 版本范围

6 项架构重构（P0+P1+P2 全套，不含 P3 枚举化）：

1. **拆 blind_aggregator.rs 1790 LOC → 3 子文件**（T12-1，P0）：logsign/blind/ 目录下 probe.rs（探针抽取+正则）/ aggregate.rs（位置聚类+true_size 众数算法）/ reconstruct.rs（数据库还原+read_target 解析），blind/mod.rs 入口 + pub use 重导出。
2. **拆 commands.rs 32 命令 → 10 领域子文件**（T12-2，P0）：src-tauri/src/commands/ 目录下 file/mask/validate/export/ruleset/log/pcap/extract/search/tools 各自承载同领域命令，mod.rs 重导出，main.rs 引用路径不变。
3. **拆 operator.rs 976 LOC → mask_op.rs + validate_op.rs**（T12-3，P1）：MaskOp + 4 变体 + apply + from_params helpers 归 mask_op.rs；ValidateOp + 3 变体 + from_rule + apply 归 validate_op.rs。
4. **建 rules/patterns.rs 集中正则表**（T12-4，P1）：8 种 scope 的 extract + validate 正则成对集中定义，消除 scan/extract_pattern 与 validators/*.rs 双正则源，消除 phone `^1\d{10}$` 跨 6+ 文件硬编码。
5. **前端 state.js 按领域切片 + action 常量化**（T12-5，P2）：29 个 action type 抽常量对象，reducer 内部按 11 个领域分组为子函数，组件 dispatch 调用签名不变。
6. **抽 ColumnRuleMapper 公共组件**（T12-6，P2）：封装 MaskView/ValidateView 重复的「表头-规则映射 Table + 下拉 + 摘要 + 清空」结构，两 View 段②改消费公共组件。
