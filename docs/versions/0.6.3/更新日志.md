## 变更明细

### T18-1 修复脱敏/校验视图总行数显示（P0）

- **根因**：后端 `MaskSummary` / `ValidateSummary` 用 `serde::Serialize` 序列化为 `total_rows` / `masked_rows` / `invalid_rows`，但前端 MaskView.jsx 读 `summary.total`、ValidateView.jsx 读 `summary.total` / `summary.valid_count` / `summary.invalid_count`（均为不存在的字段），导致 UI 始终显示 `-`。
- **修复 MaskView.jsx**（5 处）：`.total` → `.total_rows`。
  - `onApply` 内 actionHint 拼接（line 135-136）
  - 脱敏后 Tag 行数显示（line 226-227）
  - 脱敏后辅助文案（line 233-234）
  - 预览区共 N 行（line 243-246）
- **修复 ValidateView.jsx**（4 处）：
  - `summaryText` useMemo：`s.total` → `s.total_rows`、`s.invalid_count` → `s.invalid_rows`、`s.valid_count` → 计算 `total_rows - invalid_rows`（line 128-130）
  - 校验后 Tag 行数（line 244）：`.total` → `.total_rows`
  - 合法/非法 Tag（line 248-254）：`.valid_count` → 计算 `total_rows - invalid_rows`；`.invalid_count` → `.invalid_rows`
- 验证：`npm --prefix frontend run build` 绿；`grep` 确认无残留 `.total`/`.valid_count`/`.invalid_count` 字段读取。

### T18-2 RegexTool 构造 Tab 改为可视化积木构建（P0）

- **重构动机**：原 ConstructTab 使用自然语言描述 → 后端 `construct_regex` 规则化推断，仅识别 6 类线索（位数/字符集/锚定前缀/邮箱/URL/身份证），用户描述稍微偏离模板就无法构造，「几乎没有实质性功能」。
- **新方案**：纯前端可视化积木构建。用户点选模块按钮按顺序拼装正则字符串，实时预览 + 测试样例高亮，全程零网络调用（与 §6 安全约束一致）。
- **新增文件 `frontend/src/components/RegexConstructTab.jsx`**（~300 LOC）：
  - 5 类积木模块共 21 个：
    - **字符类**（11）：数字 `\d` / 非数字 `\D` / 单词字符 `\w` / 非单词字符 `\W` / 空白 `\s` / 非空白 `\S` / 字母 `[A-Za-z]` / 大写 `[A-Z]` / 小写 `[a-z]` / 十六进制 `[0-9a-fA-F]` / 任意字符 `.` / 自定义字符集 `[...]`
    - **量词**（5）：至少一次 `+` / 零或多次 `*` / 可选 `?` / 精确 N 次 `{n}`（弹窗收集 N）/ 范围 `{m,n}`（弹窗收集 m,n）
    - **锚定**（2）：行首 `^` / 行尾 `$`
    - **分组/选择**（2）：分组 `()` / 或 `|`
    - **字面量**（1）：自定义字面量（弹窗收集，自动转义元字符）
  - 3 个预设模板一键载入：11 位手机号 `^1[3-9]\d{9}$` / 邮箱 `^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$` / 18 位身份证 `^\d{17}[\dXx]$`
  - 积木序列可视化：Tag 列表 + → 箭头分隔，每个 Tag 可 closable 删除，整体支持撤销/清空
  - 构造结果区：实时拼装的 pattern `Paragraph` copyable + 测试样例 `Input` + 测试按钮 + 命中片段 `<mark>` 高亮（复用原 `highlightMatches` 函数）
  - 参数收集弹窗（antd Modal）：精确 N 次 / 范围 {m,n} / 自定义字面量 / 自定义字符集，InputNumber 或 Input 收集，回车确认
  - 状态自包含于组件内部（`useState` blocks/modal/testInput/testError/testHighlight），不污染全局 state；切 view 回来不保留（积木构造是即用即弃操作，与解析 Tab 全局 state 不同）
- **修改文件 `frontend/src/components/RegexTool.jsx`**：
  - 删除原 ConstructTab（自然语言输入 → `regexConstruct` 后端调用）
  - 改为 `import RegexConstructTab from "./RegexConstructTab.jsx"` + Tabs items construct children 渲染新组件
  - ExplainTab 保持不变
  - 不再 import `regexConstruct` from tauri.js（后端 `regex_construct` 命令保留但前端不再调用）
- **后端 `crates/core/src/tools/regex_construct.rs`**：保留不动（向后兼容源码可读，`regex_construct` Tauri 命令仍注册，便于历史回溯）。
- 验证：`npm --prefix frontend run build` 绿（3009 modules transformed，+1 module 对比 v0.6.2 的 3008）。
