## 变更明细

### T16-1 4 视图统一加醒目总行数（P0）

- `MaskView.jsx`：原始数据 Card extra 加 `<Tag color="blue" fontWeight=600>原始数据 N 行</Tag>`（rowCount）；脱敏预览 Card extra 加「脱敏后 N 行」（maskedSummary.total，未脱敏显示「-」）。
- `ValidateView.jsx`：原始数据区「原始数据 N 行」；校验预览区「校验后 N 行 / 合法 N（green）/ 非法 N（red）」（validateResult.summary，未校验时不渲染合法/非法 Tag）。
- `PreprocessView.jsx`：预览 Card extra 加「总行数 N 行」（records.rowCount）。
- `ExportView.jsx`：新增 `sourceTotalRows` useMemo，按 exportSource 取对应数据源行数（raw/records→records.rowCount，masked→maskedSummary.total，validate→validateResult.summary.total，未对应→null），源数据 Select 上方插入「总行数 N 行」Tag（null 时显示「-」）。
- 视觉权重：`Tag color="blue" fontWeight=600` 区别于既有 12px 灰色角落字；保留「共 N 行 / 显示前 N 行」预览截断提示；null/0 优雅降级不报错。
- 不新增 state action，全部复用现有 state 字段（records.rowCount / maskedSummary.total / validateResult.summary）。

### T16-2 RulesView 默认全部收起（P0）

- `RulesView.jsx`：`useState(maskKeys)` → `useState([])`（默认收起所有规则行）；maskers 变化时 useEffect 重置为 `[]`（不再全展开 mask 行）。
- 保留 maskKeys/filteredMaskKeys/toggleAll/allExpanded 逻辑与「全部展开/收起」按钮（初始 allExpanded=false）。
- 组件头注释同步更新：默认展开 → 默认收起，点击展开。
