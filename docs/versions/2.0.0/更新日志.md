## 版本摘要

v2.0.0 是 RuT0DataKit 的设计理念级重构：从 v0.x 的「侧边栏多独立视图」范式，改为「以表格工作台为中心」的单页工作台范式。中央表格占 70% 作为唯一主舞台，上方工具栏承载高频操作，左侧操作栏承载中频能力，右侧 AI 面板预留占位（v2.0 不实现真实 AI）。v0.6.x 的脱敏/校验/提取/导出/规则/搜索/Tools/日志扫描/PCAP 扫描/设置十项能力全部迁移到工作台范式，功能等价、交互升级。`crates/core` 业务逻辑零重写，Tauri 命令层围绕 Sheet/选区/列操作重组。

## 更新内容

### 新增

- 工作台 Shell 三栏布局（Toolbar / OperationBar / Workbench 70% / AIPanel 占位）。
- Sheet/Tab 模型：多源数据以 Sheet 承载，"当前活动表"为唯一操作对象，替代 v0.x activeView 状态机。
- 中央 WorkbenchTable 组件：选区 + 列勾选 + 列序 + 分页 + cell 状态高亮（原始/脱敏/非法/提取标记）。
- 工作台语义 Tauri 命令：`import_to_sheet` / `mask_selection` / `validate_sheet` / `extract_from_sheet` / `export_sheet` / `scan_log_to_sheet` / `scan_pcap_to_sheet`。
- 右侧 AI 面板占位 + 预留 IPC 契约（`ai_suggest` / `invoke_ai_op` 空实现命令，返回 `not_implemented`）。

### 修复

- 无（v2.0 是范式重构，不是 bugfix 版本；既有 bug 已在 v0.6.x 修复）。

### 调整

- 放弃 v0.x 侧边栏多视图范式（Sidebar/PreprocessView/MaskView/ValidateView/ExportView/ExtractView/RulesView/SearchView/ToolsView/SettingsView 等 view 组件迁移后清理）。
- 前端 `state.js` 由领域切片重构为 Sheet 模型 reducer + 全局 rules/settings 切片。
- Tauri 命令层由按 view 组织重组为按操作对象组织（sheet_ops / mask_ops / validate_ops / extract_ops / scan_ops / ruleset_ops / tools_ops / ai_ops）。
- 版本号 0.6.8 → 2.0.0（5 处 manifest 同步）。
