# v0.4.4 更新日志

> 规则引擎三步重构：删除添加规则 UI + 规则模版 → 重构字段为 tag/scope 双维度 → 内置规则启动加载。

## 版本范围

5 项变更（三步重构 + 内置规则 + 文档）：

1. **删除添加规则 UI + 规则模版**（T11-2）：删除前端 `RuleDrawer.jsx` / `RuleForm.jsx` / `RulesPanel.jsx` / `RuleDocPanel.jsx` / `ParamField.jsx` / `maskerDefs.js` / `validatorDefs.js`；删除 `rules/default_mask.yaml` 与 `rules/custom_example.yaml` 两个预置模版文件；移除 `load_default_mask_ruleset` / `list_tagged_presets` / `list_mask_op_types` / `list_validate_op_types` 旧 API。规则改代码内部维护，暂不重建添加入口（用户明确「彻底删除，暂不重建」）。
2. **重构规则引擎字段**（T11-1/T11-3）：`FieldRule` / `MaskRule` 由旧字段（`validator` / `masker` / `regex` / `tags: Vec<String>`）迁移为新 schema `{ field, scope, tag, params, message, description }`。`RuleSet` 加 `#[derive(Serialize)]`（供 `list_builtin_rules` 序列化）。`RuleSet::by_tag` / `by_tag_mask` 改单值匹配。
3. **添加规则标签（tag）筛选**：`list_rule_tags` 返回 `["extract","mask","validate"]`；`RulesView.jsx` / `ExtractView.jsx` 顶部 Select 按 tag 过滤；`tag` 为单值字符串（非数组）。
4. **添加规则范围（scope）**（T11-1）：`scan::extract_pattern(scope)` 查表覆盖 idcard/phone/bankcard/email/ip/mac/username/name 八种 → `find_iter` 候选 → `build_validator(rule, &reg).validate()` → 仅 valid==true 记 finding。`builtin_ruleset()` 返回 phone/bankcard/ip 三条提取规则（按 PDF spec：手机号 `^1\d{10}$`、银行卡 13-19 位 + Luhn、IP IPv4 四段 0-255 拒绝前导零）。
5. **内置规则加载**（T11-3）：`list_builtin_rules` Tauri 命令 + `src-tauri/main.rs` 注册；前端 `tauri.js` `listBuiltinRules()` 封装；`App.jsx` 启动 `useEffect` 调 `listBuiltinRules()` → `dispatch SET_RULES` 写入 `state.rules`；`ExtractView.jsx` 文案修正（`validator` → `scope`）。

## 破坏性变更

- `FieldRule` / `MaskRule` 字段变更：`validator`/`masker`/`regex`/`tags: Vec` → `scope`/`tag`/`params`。旧 YAML 不含 `tag` 会反序列化失败（预期行为，规则池不再从 YAML 加载）。
- `load_default_mask_ruleset` / `list_tagged_presets` / `list_mask_op_types` / `list_validate_op_types` API 删除。
- `rules/default_mask.yaml` / `rules/custom_example.yaml` 删除。
- 前端添加规则 UI（RuleDrawer/RuleForm）删除，暂不重建。
