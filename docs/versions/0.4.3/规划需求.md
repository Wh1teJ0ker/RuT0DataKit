# v0.4.3 规划需求

## 范围

**txt 兼容 + 数据提取模块 + 规则引擎去绝对化**：3 项主功能。

1. **txt 兼容**（T9-1）：PreprocessView 文件选择对话框新增 `.txt`；core 新增 `TxtReader` + `SourceType::Txt` + `detect_type("a.txt") => Txt`。
2. **数据提取模块**（T9-3 + T9-4 + T9-5）：左侧导航新增独立模块「数据提取」（ExtractView）。输入支持文件导入 + 文本粘贴二选一。按 PDF spec 提取 phone/bankcard/ip 三类 PII。导出支持 txt（每行 `type_value`，匹配 PDF spec 输出格式）/ csv / json 三种格式，复用已有导出模块。
3. **规则引擎去绝对化**（T9-2）：删除 `PhoneValidator` 的 CTF/real 前缀白名单（仅按 PDF spec `^1\d{10}$` 校验）；新增 `IpValidator` 注册为内置校验器；`scan/mod.rs::extract_pattern` 加 `"ip"` 条目。

## 目标

### 1. txt 兼容（T9-1）

- core 新增 `crates/core/src/readers/txt_reader.rs`：仿 SqlReader，`read_to_string` 整段文本 → `Records { headers: ["content"], rows: [[整段文本]] }`。
- `pipeline/mod.rs`：`SourceType` 新增 `Txt`；`detect_type` 新增 `"txt" => Txt`。
- `readers/mod.rs`：`pub mod txt_reader;` + dispatch arm。

### 2. 规则引擎去绝对化 + IpValidator（T9-2）

- `validators/phone.rs` 全文重写：删 CTF_PREFIXES / REAL_PREFIXES / ctf_prefixes() / real_prefixes() / OnceLock / HashSet；`PhoneValidator { re }` 编译 `^1\d{10}$`。
- 新增 `validators/ip.rs`：`IpValidator { re }` 用 `IP_REGEX`，注册为第 8 个内置校验器。
- `scan/mod.rs::extract_pattern` 加 `"ip"` 条目（带 word boundary）。

### 3. extract pipeline（T9-3）

- core 新增 `crates/core/src/extract/mod.rs`：`builtin_extract_ruleset`（phone/bankcard/ip 三 validator）+ `extract_text(content) -> Vec<Finding>` + `extract_file(path) -> Result<Vec<Finding>, CoreError>`，复用 `DefaultSensitiveScan`。

### 4. Tauri 命令（T9-4）

- 新增 3 命令：`extract_text(content)` / `extract_file(path)` / `export_extract(findings_json, format, out_path)`。
- `select_file` filter 加 `"txt"`；`source_type_name` 加 `Txt` arm。
- `main.rs` `generate_handler![]` 注册三命令。
- 版本号 0.4.2 → 0.4.3（4 处：`src-tauri/Cargo.toml` + `tauri.conf.json` + `frontend/package.json` + README 状态行）。

### 5. 前端 ExtractView（T9-5）

- `state.js`：4 字段（extractMode="file" / extractInput="" / extractResult=null / extractLoading=false）+ 4 reducer case。
- `tauri.js`：3 camelCase 封装。
- `Sidebar.jsx`：items 数组在 export 后插入 `{ key: "extract", icon: <FilterOutlined />, label: "数据提取" }`。
- `App.jsx`：import + `view === "extract"` 路由分支。
- `ExtractView.jsx`（NEW）：4 Card 布局（输入 Radio + TextArea / 操作 开始提取 / 结果 Table + 计数 Tag / 导出 3 按钮）。
