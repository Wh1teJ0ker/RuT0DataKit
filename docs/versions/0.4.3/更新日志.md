# v0.4.3 更新日志

> txt 兼容 + 「数据提取」新模块 + 规则引擎去绝对化。

## 版本范围

3 项主功能：

1. **txt 兼容**（T9-1）：PreprocessView 文件选择对话框新增 `.txt`；core 新增 `TxtReader` + `SourceType::Txt` + `detect_type("a.txt") => Txt`；PreprocessView 可导入 .txt 文件预览。
2. **数据提取模块**（T9-3 + T9-4 + T9-5）：左侧导航新增独立模块「数据提取」（ExtractView）。输入支持文件导入 + 文本粘贴二选一。按 PDF spec（`tests/fixtures/samples/tips/附件/数据格式规范文档.pdf`）提取 phone/bankcard/ip 三类 PII。导出支持 txt（每行 `type_value`，匹配 PDF spec 输出格式）/ csv（type,value 两列）/ json（结构化数组）三种格式，复用已有导出模块（write_csv / write_json）+ 新增 type_value 拼接逻辑。
3. **规则引擎去绝对化**（T9-2）：删除 `PhoneValidator` 的 CTF_PREFIXES / REAL_PREFIXES 白名单常量与相关函数（仅按 PDF spec `^1\d{10}$` 校验）；新增 `IpValidator`（用 `IP_REGEX`）注册为第 8 个内置校验器；`scan/mod.rs::extract_pattern` 表新增 `"ip"` 条目，让敏感扫描也能在文本中提取 IP 候选并校验。
