### T24-2 PreprocessView 列级 SQL 解析按钮 + 跳转 Tools/Sql（P0）

#### ① `frontend/src/components/PreprocessView.jsx`

**imports 新增**：

- `ConsoleSqlOutlined` from `@ant-design/icons`（与 Sidebar 同款 SQL 图标，保持视觉一致）
- `parseSqlTool` from `../tauri.js`（复用 Tools/Sql 同款 Tauri 命令封装）

**新增 `handleColumnSqlParse(columnName)` handler**（在组件顶部，紧跟 `showError`）：

```js
const handleColumnSqlParse = async (columnName) => {
  if (!records) return;
  const sqls = [];
  for (const row of records.rows || []) {
    const c = records.headers.indexOf(columnName);
    if (c < 0) break;
    const v = row[c];
    if (v == null) continue;
    const s = String(v).trim();
    if (s !== "") sqls.push(s);
  }
  if (sqls.length === 0) {
    message.warning(`列「${columnName}」没有非空值可解析`);
    return;
  }
  const inputs = sqls.map((sql) => ({
    sql,
    responseBodySize: null,
    sourceIp: null,
  }));
  try {
    const result = await parseSqlTool(inputs);
    const text = sqls.join("\n");
    dispatch({ type: "SET_SQL_PARSE_INPUT", sqlParseInput: text });
    dispatch({ type: "SET_SQL_PARSE_RESULT", sqlParseResult: result });
    dispatch({ type: "SET_VIEW", activeView: "tools" });
    dispatch({ type: "SET_TOOLS_ACTIVE_TAB", toolsActiveTab: "sql" });
  } catch (e) {
    showError(`SQL 解析失败: ${e}`);
  }
};
```

**`previewColumns` 表头 `<Space>` 内新增 SQL 解析按钮**（在现有 ✏ 重命名按钮旁）：

```jsx
title: (
  <Space size={4} align="center" wrap={false}>
    <span>{h}</span>
    <Button
      type="text"
      size="small"
      icon={<ConsoleSqlOutlined />}
      onClick={() => handleColumnSqlParse(h)}
      title="将该列全部非空行作为 SQL 探针序列解析，跳转 Tools/SQL"
    />
    <Button
      type="text"
      size="small"
      icon={<EditOutlined />}
      onClick={() => handleRenameOne(h)}
      title="重命名此字段"
    />
  </Space>
)
```

#### ② `SqlParseTool.jsx` 不修改

已读取 `state.sqlParseInput`（`onParse` 拆行提交）+ `state.sqlParseResult`（render 渲染还原表 / 探针 / payload）。预填后用户落地即在 Tools/Sql 看到解析结果，可继续编辑 textarea 重跑。

#### ③ 跳转模式（镜像 Sidebar.jsx:60-62）

```js
dispatch({ type: "SET_VIEW", activeView: "tools" });
dispatch({ type: "SET_TOOLS_ACTIVE_TAB", toolsActiveTab: "sql" });
```

与 Sidebar 点击「Tools → SQL 解析」完全同款，无新 action type，无新 state 字段。

#### ④ 边界处理

- **空列**（该列所有单元格为空或全为空白）：`message.warning` 提示，**不跳转**，不清空已有解析结果
- **解析失败**（`parseSqlTool` 抛错）：`message.error` 提示，**不清空**已有 `sqlParseInput` / `sqlParseResult`（用户可继续使用上一次结果）
- **跳转后原 records 保留**：`SET_VIEW` 仅切换视图（reducer 不清 `records`），与 Pattern B「RulesView apply-and-jump」一致，用户回到 PreprocessView 仍可继续操作其它列

#### ⑤ 验证

- `npm --prefix frontend run build` → **0 error**
- E2E 链路（手动验证项）：
  - 导入含 SQL 探针列的 csv → PreprocessView 预览表头点 ConsoleSqlOutlined 图标
  - 跳转到 Tools/Sql，textarea 已填多行 SQL（每行一条），下方已渲染还原表 / 探针明细 / parsed_payloads
  - 改 textarea 内容 → 点「解析」按钮 → 重跑生效
  - 点击空列的 SQL 按钮 → 警告「列「xxx」没有非空值可解析」，不跳转
