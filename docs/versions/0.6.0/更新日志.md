## 变更明细

> 本版本为骨架状态，变更明细将在各任务实施后回填。

### T13-1 core encrypt 模块（P0）

- `crates/core/src/tools/encrypt.rs`（NEW）：AES-CBC（PKCS7）+ Base64 + Hex 加密 / 解密；新增 `crypto` crate 依赖版本钉定。
- 单测：加密→解密互逆、密钥 / IV 长度校验、空串与边界。

### T13-2 Tauri encrypt 命令（P0）

- `src-tauri/src/commands/tools.rs`：新增单值 + 批量列加密 / 解密命令（同步 `Result<_, String>`）。
- `commands/mod.rs` + `main.rs` invoke_handler 注册。
- 批量命令对未选列原样透传。

### T13-3 前端 EncryptTool（P0）

- `frontend/src/components/tools/EncryptTool.jsx`（NEW）：单值试运行 + 批量列预览（表头勾选 + 结果 Table）。
- `tauri.js` camelCase 封装 + `state.js` encrypt 域切片 + `Sidebar` / `ToolsView` 下拉栏接线。

### T13-4 docs 骨架（P1）

- `docs/versions/0.6.0/规划需求.md`（NEW）+ `docs/versions/0.6.0/更新日志.md`（NEW）。
