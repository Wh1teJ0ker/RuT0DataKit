## 变更明细

### T13-1 core encrypt 模块（P0）

- `crates/core/src/tools/encrypt.rs`（NEW）：AES-CBC（PKCS7 padding，固定 IV `0x00..0x10`）+ Base64 + Hex 加密 / 解密。
- `parse_algo`：`aes` / `aes-cbc` → Aes；`base64` → Base64；`hex` → Hex。
- `parse_key`：AES 要求 16/24/32 字节密钥；Base64/Hex 模式 key 不参与加解密（前端 Key 仅 AES 显示）。
- 单测：加密→解密互逆、AES 三档密钥长度（16/24/32 字节）、空串与边界、Base64/Hex 互逆、非法 algo/密钥长度错误路径。

### T13-2 Tauri encrypt 命令（P0）

- `src-tauri/src/commands/encrypt.rs`（NEW）：4 个 `#[tauri::command]`：
  - `encrypt_text(algo, plaintext, key)` / `decrypt_text(algo, ciphertext, key)` —— 单值
  - `encrypt_columns(headers, rows, algo, key, selectedColumns)` / `decrypt_columns(...)` —— 批量列
- 批量命令对未选列原样透传；selectedColumns 为列名集合。
- `commands/mod.rs` + `main.rs` invoke_handler 注册 4 命令。
- `Result<_, String>` 错误统一 String 化（前端 Alert 展示）。

### T13-3 / T15-2 前端 EncryptTool（P0）

- `frontend/src/components/EncryptTool.jsx`（NEW）：三段结构：
  1. **配置区**：算法 Select（aes/base64/hex）+ 模式 Radio（加密/解密）+ Key Input.Password（仅 AES 显示）
  2. **单值试运行**：TextArea + 运行按钮 → `encryptText`/`decryptText` → Paragraph copyable / Alert 错误
  3. **批量列操作**：Checkbox.Group（options=headers）+ 运行按钮 → `encryptColumns`/`decryptColumns` → Table 预览前 50 行（`ENCRYPT_PREVIEW_ROW_LIMIT=50`，`scroll.y=360`），errors>0 时 message.warning 提示失败 cell 数
- AES 模式 Key 为空前端阻断：`ensureKey()` → `message.warning("AES 模式需要填写 Key")`，覆盖单值与批量两条路径。
- 切 view 不重置子状态（与 sql/regex 一致策略）。
- `tauri.js`：4 wrapper（`encryptText`/`decryptText`/`encryptColumns`/`decryptColumns`），invoke 名与参数 camelCase 对齐 `commands/encrypt.rs`。
- `state.js`：7 ACTION 常量（`ENCRYPT_ALGO_SET`/`ENCRYPT_MODE_SET`/`ENCRYPT_KEY_SET`/`ENCRYPT_INPUT_SET`/`ENCRYPT_RESULT_SET`/`ENCRYPT_COLUMNS_RESULT_SET`/`ENCRYPT_LOADING_SET`）+ 7 initialState 字段 + toolsDomain 7 case；`SET_RECORDS` 级联逻辑保持不变。
- `Sidebar.jsx`：tools SubMenu 加第三子项 `{ key:"tools.encrypt", icon:<LockOutlined/>, label:"加密/解密" }` + handleClick 分支。
- `ToolsView.jsx`：加 encrypt 分支渲染 `<EncryptTool>`，title 三元。

## 安全约束

- **不外发数据**：全本地处理；规则与样本不上传（保留 v0.1.0 §6 安全约束，v0.6.0 不变）。
- AES-CBC 使用固定 IV（`0x00..0x10`）——本工具定位为本地数据脱敏辅助工具，非生产级密文传输；IV 固定便于单值试运行可复现，密钥不落盘、不记录。
- 加密 / 解密全部在本地进程内完成，无任何网络调用（`grep -rn 'reqwest\|http\|net' crates/core/src/tools/` 0 命中）。
