# v0.6.0 规划需求

> 新功能版本：Tools 下新增加密 / 解密器，支持 AES-CBC / Base64 / Hex 单值与指定列批量，纯本地无网络。

## 版本范围

4 项任务（依据 `handoff/TASK-BOARD.md` v0.6.0 任务 DAG）：

1. **core tools/encrypt.rs 加密模块**（T13-1）：`crates/core/src/tools/encrypt.rs` 实现 AES-CBC（PKCS7 填充）+ Base64 + Hex 三算法的加密 / 解密，新增 `crypto` 依赖版本钉定；单测覆盖加密→解密互逆、密钥 / IV 长度校验、空串与边界。
2. **Tauri encrypt 命令**（T13-2）：`src-tauri/src/commands/tools.rs` 新增单值加密 / 解密 + 指定列批量加密 / 解密命令（同步 `Result<_, String>` 风格），`mod.rs` + `main.rs` invoke_handler 注册；批量命令对未选列保持原样透传。
3. **前端 EncryptTool.jsx + 接线**（T13-3）：`frontend/src/components/tools/EncryptTool.jsx` 单值试运行 + 批量列预览（表头勾选 + 结果 Table）；`tauri.js` camelCase 封装 + `state.js` encrypt 域切片 + `Sidebar` / `ToolsView` 下拉栏接线。
4. **docs/versions/0.6.0 文档骨架**（T13-4）：新建 `规划需求.md` + `更新日志.md`，里程碑索引追加 v0.6.0 行（状态 `planned`），内容与 TASK-BOARD 对齐。

## 不做

- **SM4 / 国密对称算法**：推迟到后续版本。
- **RSA / 非对称加密**：本版仅做对称 AES-CBC，非对称推迟。
- **KDF（密钥派生函数，如 PBKDF2 / HKDF / scrypt / Argon2）**：本版密钥由用户直接传入，不做派生。
- **GCM / CTR 等其他 AES 模式**：本版仅 AES-CBC，其他模式推迟。
- **密钥持久化 / 落盘**：密钥仅运行时持有，不写文件 / 不写 settings.json。
- **网络调用**：encrypt.rs 纯本地实现，不引入 reqwest / http / ureq。
