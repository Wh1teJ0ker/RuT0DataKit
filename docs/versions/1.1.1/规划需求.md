# v1.1.1 规划需求

> 本文件为 v1.1.1 版本子文档，范围与任务清单与 [`docs/03-开发任务清单.md`](../../03-开发任务清单.md) §7 对齐。版本状态口径见 [`docs/04-版本标准.md`](../../04-版本标准.md)。

## 1. 版本定位

v1.1.1 在 v1.1.0（脱敏 / 校验 / 提取原型 + rules 表持久化）之上，交付四大功能：

1. **撤销 / 重做**：`mask_column` / `replace_in_column` / `replace_all` 三类就地变更操作可撤销可重做；优化 DB 交互，避免纯内存阶段，保证数据可保存。
2. **列操作**：(1) `parse_column_as_json`——将某列以 JSON 格式解析，展开成多列写入新 sheet / Tab；(2) `replace_in_column`——某列批量字段替换。
3. **搜索**：关键字 + 正则搜索（`search_cells`）+ 全局搜索替换（`replace_all`）；优化索引算法（`idx_cells_sheet_col` 复合索引 + 服务端分页）避免大文件卡顿。
4. **测试优化**：commands 层新增测试（首个 commands 层测试，覆盖 undo/redo + 搜索 + 列操作），更全面详细。

DB schema 从 `SCHEMA_VERSION=2` 升至 `3`：`operations` 表新增 `before_snapshot_json` 列（撤销前置快照）；新增 `idx_cells_sheet_col` 复合索引供搜索加速；`DbManager` 新增 8 个方法（`log_operation_with_snapshot` / `query_column_cells_with_row_idx_range` / `search_cells` / `search_cells_regex` / `count_search_results` / `replace_in_column_cells` / `replace_all_cells` / `query_operation_by_id`），全部参数化 SQL（`?N` + `params![]`）。

## 3. 验收标准（v1.1.1）

1. `cargo fmt --check` / `cargo clippy --workspace -- -D warnings` / `cargo test --workspace` 全通过（含 commands 层新增测试 + DB 层 39 tests）。
2. `pnpm --prefix frontend install --frozen-lockfile && pnpm --prefix frontend build` 通过。
3. 撤销 / 重做：mask 后点撤销 → cells 恢复原值；点重做 → cells 重新脱敏；replace_in_column / replace_all 同样可撤销。
4. 列操作：选 JSON 列 → 解析为新 Tab → 新 Tab 含展开列；列内替换 → 该列命中值替换，其他列不变。
5. 搜索：关键字 → 命中单元格高亮（`<mark>` #fff48f）；正则模式可用；分页正确（total 为总数）。
6. 全局替换：from/to → 全表命中替换 → 撤销可恢复。
7. 版本号 6 处一致为 `1.1.1` / `v1.1.1`。
8. DB schema 升级为 `SCHEMA_VERSION=3`，含 `before_snapshot_json` 列 + `idx_cells_sheet_col` 索引；v2→v3 增量迁移幂等；重启应用后历史数据保留。

## 4. 技术约束

- **SQL 参数绑定**：所有外部输入（sheet_id / column / keyword / from / to / pattern）必须用 `?N` + `params![]` 绑定，禁止字符串拼接 SQL。
- **LIKE 转义**：关键字搜索时转义 `%` / `_` / `\`，避免用户输入改变 LIKE 语义。
- **正则编译**：用户输入的正则模式在 Rust 侧用 `regex::Regex::new` 编译，失败返回明确错误，不 panic。
- **快照大小**：before / after 快照仅存被修改列的 cells（非全表），避免 `operations` 表膨胀。
- **事务边界**：replace 操作在单事务内完成（before 快照 + write_cells + log_operation），保证原子性。
- **撤销范围**：仅就地变更操作（mask / replace_in_column / replace_all）；import / parse_json / validate / extract / undo / redo 本身不入撤销栈。
- **搜索索引**：LIKE + 复合索引（`idx_cells_sheet_col`）+ 服务端分页，不引入 FTS5。

- **搜索索引**：LIKE + 复合索引 + 分页（不引入 FTS5）。
- **撤销范围**：仅就地变更操作（mask / replace_in_column / replace_all）；import / parse_json / validate / extract 不入撤销栈。
