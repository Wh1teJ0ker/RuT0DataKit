## 本期目标

在 v1.1.0 基础上完成四大功能：

1. **撤销/重做**：mask / replace_in_column / replace_all 操作可撤销可重做；优化 DB 交互，避免纯内存阶段，保证数据可保存。
2. **列操作**：(1) 将某列以 JSON 格式解析，展开为新 Tab；(2) 某列批量字段替换。
3. **搜索**：关键字 + 正则搜索，全局搜索替换，优化索引算法避免大文件卡顿。
4. **测试优化**：commands 层新增测试，更全面详细。

## 关键设计决策

- 搜索索引：LIKE + 复合索引（idx_cells_sheet_col）+ 分页，不引入 FTS5。
- 撤销范围：仅就地变更操作（mask / replace_in_column / replace_all）；import / parse_json / validate / extract 不入撤销栈。
- 安全约束：所有 SQL 用 `?N` + `params![]` 参数绑定；LIKE 转义 `%`/`_`/`\`；正则编译失败返回错误不 panic；快照仅存变更列 cells。
