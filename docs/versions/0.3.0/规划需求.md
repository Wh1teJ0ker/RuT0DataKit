# v0.3.0 规划需求

## 范围

流量包处理切片：PCAP/PCAPNG 解析、HTTP 字段提取、参数解码、base64 片段重组、敏感数据扫描、JSON 报告。

## 目标

- tshark 子进程调用 → TSV → HttpRequest。
- 双重 URL 解码 + base64 片段重组（按规则 `reassemble_base64.param` 拼接 chunk 解出明文）。
- 复用 v0.1.0/v0.2.0 的 SensitiveScan + Report/Finding，产出 Report(kind=pcap)。
- GUI pcap 入口启用 + tshark 缺失提示与禁用逻辑激活。
- tshark 不存在时返回 CoreError::DependencyMissing("tshark")，不 panic。
