## 变更明细

### T19-1 ExtractView 全面重构 — state 隔离 + 导出自定义 + 单/批量勾选（P0）

#### ① 文件导入 vs 文本粘贴数据隔离

- **根因**：`extractInput` / `extractResult` 在两种导入方式间共用，切 Radio 时 `SET_EXTRACT_MODE` 只设 `extractMode`，不清空对方输入与结果 → 粘贴后点文件导入出现所有数据且未优化显示。
- **修复 `frontend/src/state.js`** `extractDomain` 的 `EXTRACT_MODE_SET` case：切 mode 时级联清空 `extractInput = ""` / `extractResult = null`。规则选择与 tag 过滤保留。参照 `SET_FILE` 的级联清空写法（state.js:222-251）。
- 符合 `docs/01-页面与交互说明.md:292`「切换 Radio 时清空当前输入与结果」交互规范。
- `ExtractView.jsx` 输入区追加提示文案「切换模式会清空当前输入与结果，文件导入与文本粘贴数据互不串扰」。

#### ② 导出格式自定义 + 单/批量勾选

- **后端 `src-tauri/src/commands/export.rs`** `export_extract` 命令签名扩展（+3 参数）：
  - `template: Option<String>` — txt 模板，占位符 `{type}` / `{value}`，默认 `{type}_{value}`
  - `selected_columns: Option<Vec<String>>` — csv/json 字段子集
  - `column_order: Option<Vec<String>>` — csv/json 字段顺序
  - txt 分支：按模板逐行 `replace("{type}", ...).replace("{value}", ...)` + `\n`
  - csv/json 分支：按 `resolve_order()` 解析最终列顺序（默认 `["type","value"]`），投影字段值
- **前端 `frontend/src/tauri.js`** `exportExtract(findings, format, outPath, opts = {})` 增加 opts 参数透传。
- **前端 `frontend/src/components/ExtractView.jsx`** 导出区重构：
  - TXT 模板输入框（localStorage 持久化 `extractTxtTemplate`，占位符提示）
  - CSV/JSON 字段勾选 Checkbox + 上下移按钮（移植 ExportView 模式，精简为 type/value 两列）
  - 结果表加 `rowSelection={{ selectedRowKeys, onChange }}`，本地 useState 管理勾选行
  - 导出时：有勾选 → 仅导出勾选行子集；无勾选 → 全量导出（保留原行为）
  - 成功 toast 提示「选中 N 条」或「全部 N 条」

### T19-3 分页器受控化（P0）

- **根因**：所有带分页的 antd Table 把 `pagination` 当字面量传入，`pageSize` 写死 50 且不绑 state，无 `onChange` / `onShowSizeChange` 回调。antd v5 每次渲染把内部 pageSize 覆盖回 50 → 点「每页 10 条」不生效。
- **修复**：8 处 Table 改为受控分页：
  - `useState` 绑定 `current` + `pageSize`（默认 50）
  - `pagination={{ current, pageSize, showSizeChanger: true, pageSizeOptions: [10,20,50,100], onChange, onShowSizeChange, showTotal }}`
  - 切 pageSize 时回到第 1 页
- **8 处修改清单**：

| 文件 | 视图 |
|---|---|
| `frontend/src/components/ExtractView.jsx` | 提取结果表 |
| `frontend/src/components/SearchView.jsx` | 搜索结果表 |
| `frontend/src/components/SqlParseTool.jsx` | SQL 探针表 + payload 语义表 |
| `frontend/src/components/PcapView.jsx` | 原始 HTTP 请求表 + findings 表 |
| `frontend/src/components/LogView.jsx` | 原始日志表 + findings 表 |

## 安全约束（不变）

全本地处理，不外发数据。T19-2 导出模板渲染纯本地，`export_extract` 仅写本地文件，不外发，与 `docs/00-需求文档.md §6` 「不外发数据：全本地处理；规则与样本不上传」约束一致。T19-1/T19-3 仅改前端 state 与 UI，不涉及网络/文件 IO。
