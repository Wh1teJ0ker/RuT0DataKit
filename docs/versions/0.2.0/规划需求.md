# v0.2.0 规划需求

## 范围

日志处理切片：access.log 等 CLF 日志的解析、攻击特征识别、敏感数据扫描、JSON 报告。

## 目标

- Log reader（CLF 正则解析）→ LogEntry。
- 攻击特征签名：SQLi 6 类（盲注二分 / UNION / 报错 / 时间盲注 / 恒真 / 注释符）+ 弱口令 + 越权。
- 复用 v0.1.0 的 SensitiveScan + Report/Finding，产出 Report(kind=log_scan)。
- GUI log 入口启用 + 报告展示。
- 补齐 validators：birth / address / password / ip（v0.1.0 只落地了最小子集）。
