# v0.4.1 更新日志

> 5 项缺陷修复：针对 v0.4.0 发布后用户反馈的 5 个问题做定向修复，不引入新功能模块，不破坏 v0.4.0 架构契约。

## 版本范围

5 项缺陷修复：

1. **数据流打通**（T6-1）：ExportView 从读 `state.filePath` 迁移到读 `state.records`，与 PreprocessView 唯一写入端对齐。
2. **移除各界面 FileToolbar**（T6-2）：删除 FileToolbar.jsx + App.jsx 移除渲染分支，导入唯一入口收敛到 PreprocessView。
3. **ToolsView 下拉栏**（T6-3）：antd Tabs → antd Select，满足「下拉栏而非横版标签」诉求。
4. **SQL 盲注特征自动跳转**（T6-4）：预处理导入命中 SQL 盲注特征时自动跳转到 SqlParseTool 并预填样本。
5. **RegexTool 语句→构造正则**（T6-5）：移除内置模板 Tab，新增 ConstructTab（输入一句描述 → 自动构造可编译正则 + 解释 + 命中线索）。
