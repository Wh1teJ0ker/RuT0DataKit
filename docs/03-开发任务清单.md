# 开发任务清单

> 全局任务索引。详细边界见 `handoff/TASK-<id>-HANDOFF.md`。
> 状态口径：planned / in_progress / implemented_not_verified / partially_complete / blocked / in_review / review_passed / review_rejected / verified_complete / not_complete / done_e2e / qa_passed / release_complete

## 验收方式

- 每个任务：`cargo test -p ruT0-data-kit-core <模块>` 通过 + reviewer pass。
