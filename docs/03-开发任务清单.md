## 验收方式

- 每个任务：`cargo test -p ruT0-data-kit-core <模块>` 通过 + reviewer pass。
- 端到端：`cargo test --test e2e` 跑脱敏 + 日志 fixtures，断言见 docs/00 §4 / §4.1。
