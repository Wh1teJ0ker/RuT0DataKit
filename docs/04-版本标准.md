## 版本状态口径

- `planned`：范围已定，任务 DAG 已拆，尚未全部 verified_complete。
- `in_progress`：已开始派 coder。
- `done_e2e`：所有任务 verified_complete + 端到端集成验收通过；但未通过 Release QA。
- `qa_passed`：Release QA 审计通过，QA 报告落盘且结论 `qa_passed`。
- `release_complete`：QA 通过 + 版本文档（更新日志）同步完成。

## 发布门禁

版本状态写入 `release_complete` 前，必须：

1. 全部任务 `verified_complete`。
2. 端到端集成验收通过（`cargo test --test e2e` 全绿）。
3. Release QA 审计通过，`docs/qa/versions/<ver>/QA-审计报告.md` 结论 `qa_passed`。
4. `docs/versions/<ver>/更新日志.md` 与 TASK-BOARD 状态对齐。

  - **数据预处理归一化**：新增 `crates/core/src/readers/` 下 `SqlReader` / `JsonReader` + `PcapRecordsReader` / `LogRecordsReader` 适配器，统一入口 `read_records(path) -> Result<Records, CoreError>` 按 `detect_type` 后缀 dispatch；`SourceType` 扩 `Sql` / `Json`；Tauri 新增 `preprocess_file` 命令把任意支持格式统一读成 `{ headers, rows, source_type, row_count }` JSON。

  - **搜索模块**：新增 `crates/core/src/search/` 模块，`SearchIndex::build` 倒排索引（token → (row_idx, col_idx)），`SearchQuery` serde tag enum（`Keyword{terms,mode}` / `Regex{pattern}` / `ExactField{field,value}`），`SearchMode::Or` / `And`，`SearchHit{row_idx,col_idx,value,snippet}`；Tauri `search_records` 命令；GUI `SearchView` 3-mode `Radio.Group` + `<mark>` 高亮 + `filteredRowIndices` 写回。
  - **Tools 工具集**：新增 `crates/core/src/tools/` 模块（`sql_parse` + `regex_explain` + `regex_template`）。`sql_parse::parse_sqls(inputs) -> SqlParseResult{probes, aggregated, reconstructed, parsed_payloads}`，`extract_blind_probe` 产出 `BlindProbe{kind: ProbeKind::AsciiBinary|Equality|Length, ...}`，复用 `BlindAggregator` + `ReconstructedDatabase` 交叉关联还原 schema/table/columns/rows；`ParsedPayload` 结构透出 attack_type/technique/read_target/char_position/compared_ascii/comparator/union_columns/sleep_seconds/summary。`regex_explain::explain_regex` 手写状态机 + `regex::Regex` 校验；`regex_template` 提供 8 个预置模板（email/phone_cn/idcard_cn/ipv4/url/sql_injection_bool/sql_injection_union/mac）。Tauri 新增 `parse_sql_tool` / `explain_regex` / `generate_regex` / `list_regex_templates` 命令。
  - **前端 7 界面**：`PreprocessView`（T5-4，4 跳转按钮组）→ `RulesView`（T5-5，Drawer Select mode="tags" 多标签编辑）→ `SearchView`（T5-6）→ `MaskView`（T5-7，「仅搜索命中行」Switch 消费 `filteredRowIndices`，`effectiveMaskers` 取 `by_tag_mask("mask")` + 无标签兼容）→ `ValidateView`（T5-8，validate-tag 过滤）→ `ExportView`（T5-10，「仅导出搜索命中行」Switch 默认 on + `selectedRowIndices` 透传 + xlsx/csv/json 三格式）→ `ToolsView`（T5-12，`Tabs` 容器：`SqlParseTool` + `RegexTool`）。`Sidebar.jsx` 重构为 7 项主流程 + LogView/PcapView 向后兼容保留。
