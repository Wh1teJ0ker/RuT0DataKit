## 版本状态口径

- `planned`：范围已定，任务 DAG 已拆，尚未全部 verified_complete。
- `in_progress`：已开始派 coder。
- `done_e2e`：所有任务 verified_complete + 端到端集成验收通过；但未通过 Release QA。
- `qa_passed`：Release QA 审计通过，QA 报告落盘且结论 `qa_passed`。
- `release_complete`：QA 通过 + 版本文档（更新日志）同步完成。

## 发布门禁

版本状态写入 `release_complete` 前，必须：

1. 全部任务 `verified_complete`。
2. 端到端集成验收通过（`cargo test --test e2e` 全绿）。
3. Release QA 审计通过，`docs/qa/versions/<ver>/QA-审计报告.md` 结论 `qa_passed`。
4. `docs/versions/<ver>/更新日志.md` 与 TASK-BOARD 状态对齐。
