# 页面与交互说明

> **版本覆盖说明**：本文为 v1.0.0 框架阶段交互规范。v1.0.0 只交付四区布局 shell + Sheet/Tab 工作台 + antd Table 选区/列序 + 设置页 + AI 占位，业务功能（脱敏/校验/提取/规则/搜索/Tools/日志/PCAP）从 v1.1.0 起逐项迁移。
>
> 前端栈：React 18 + Vite 5 + Ant Design 5 + @ant-design/icons。

## 1. 主界面结构（四区布局）

单页应用，四个区域，以「中央 Workbench 为唯一主舞台」范式组织。上方工具栏承载所有高频入口（数据操作 + 能力按钮），能力按钮驱动左侧操作栏切换能力面板：

```
┌───────────────────────────────────────────────────────────────────────┐
│ 上方工具栏                                                            │
│ [导入][导出][格式][撤销][列操作][运行]  │  [脱敏][校验][提取][规则管理] │
├──────────┬────────────────────────────────────────────┬───────────────┤
│ 左侧能力面板│ 中央 Workbench（占比 70%）                  │ 右侧 AI 面板  │
│          │                                            │               │
│ ┌──────┐ │ ┌─ Sheet1 ─ Sheet2 ─ + ──────────────┐      │ AI 能力       │
│ │ 脱敏 │ │ │                                    │      │ v1.1+         │
│ │ 面板 │ │ │  antd Table                         │      │               │
│ │      │ │ │  ┌──┬──┬──┬──┐                     │      │ [占位]        │
│ │v1.1+ │ │ │  │☐│☐│☐│☐│  ← 列 checkbox 选      │      │               │
│ │释放  │ │ │  ├──┼──┼──┼──┤                     │      │               │
│ └──────┘ │ │  │  │  │  │  │  ← 选区框选/状态高亮│      │               │
│          │ │  │  │  │  │  │                     │      │               │
│          │ │  └──┴──┴──┴──┘                     │      │               │
│          │ │  < 1 2 3 ... 50 >  分页            │      │               │
│ ─────    │ └────────────────────────────────────┘      │               │
│ ⚙ 设置   │                                            │               │
└──────────┴────────────────────────────────────────────┴───────────────┘
```

> 图示为点击「脱敏」能力按钮后的状态：左侧操作栏展示「脱敏面板」。点击其他能力按钮（校验/提取/规则管理）则左侧面板切换为对应内容。v1.0.0 各能力面板均为占位提示「v1.1+ 释放」。

### 区域占比与承载

| 区域 | 占比 | 承载 | 频次 |
|---|---|---|---|
| 上方工具栏 | — | 左组：导入/导出/格式/撤销/列操作/运行；右组：脱敏/校验/提取/规则管理 | 高 |
| 左侧能力面板 | — | 由工具栏能力按钮驱动切换；底部常驻「设置」齿轮 | 中 |
| 中央 Workbench | 70% | Sheet/Tab 多页 + antd Table 选区/列选/列序/状态高亮 | 主舞台 |
| 右侧 AI 面板 | — | 占位 + 预留 IPC 契约（ai_suggest/invoke_ai_op 空实现） | 低（v1.1+） |

### 1.1 上方工具栏

固定在顶部，分左右两组，中间用竖线分隔：

**左组（数据操作）**，从左到右：

| 按钮 | v1.0.0 状态 | 行为 |
|---|---|---|
| 导入 | ✅ 可用 | 触发文件选择对话框（CSV/XLSX）→ 识别 → 新建 Sheet → 写 SQLite → 渲染 Table |
| 导出 | 占位 | 点击提示「导出能力 v1.1+」 |
| 格式 Select | 占位 | 下拉显示 CSV/XLSX/JSON 三选项，选择后提示「导出能力 v1.1+」（v1.0.0 仅 UI，不触发导出） |
| 撤销 | 占位 | 点击提示「撤销能力 v1.1+」 |
| 列操作 | ✅ 可用 | 下拉菜单：重命名列 / 删除列 / 恢复列序（对当前 Sheet 生效） |
| 运行 | 占位 | 点击提示「运行能力 v1.1+」（后续承载脱敏/校验/提取等执行入口） |

**右组（能力按钮）**，4 个按钮平铺：

| 按钮 | v1.0.0 状态 | 行为 |
|---|---|---|
| 脱敏 | 占位 | 点击 → 左侧操作栏切换为「脱敏面板」，面板内展示占位提示「数据脱敏能力 v1.1+ 释放」 |
| 校验 | 占位 | 点击 → 左侧操作栏切换为「校验面板」，面板内展示占位提示「数据校验能力 v1.1+ 释放」 |
| 提取 | 占位 | 点击 → 左侧操作栏切换为「提取面板」，面板内展示占位提示「数据提取能力 v1.1+ 释放」 |
| 规则管理 | 占位 | 点击 → 左侧操作栏切换为「规则管理面板」，面板内展示占位提示「规则管理能力 v1.1+ 释放」 |

能力按钮与左组数据操作用竖线（Divider `type="vertical"`）视觉分隔。当前激活的能力按钮高亮（`type="primary"` 或底色），未激活为默认态。同一时刻最多一个能力按钮激活。

> 搜索 / Tools 不在 v1.0.0 工具栏占位，推迟到 v1.3+ 能力落地时再加入工具栏右组。

### 1.2 左侧能力面板

左侧操作栏是一个**动态能力面板**，内容由上方工具栏右组 4 个能力按钮驱动切换，而非固定菜单：

| 状态 | 展示内容 |
|---|---|
| 未点任何能力按钮 | 空态占位（「点击上方工具栏的脱敏/校验/提取/规则管理 开始分析」） |
| 点击「脱敏」 | 脱敏面板（v1.0.0 仅占位提示「数据脱敏能力 v1.1+ 释放」） |
| 点击「校验」 | 校验面板（v1.0.0 仅占位提示「数据校验能力 v1.1+ 释放」） |
| 点击「提取」 | 提取面板（v1.0.0 仅占位提示「数据提取能力 v1.1+ 释放」） |
| 点击「规则管理」 | 规则管理面板（v1.0.0 仅占位提示「规则管理能力 v1.1+ 释放」） |

面板顶部显示当前能力名称（如「脱敏」），底部常驻一个「设置」齿轮图标按钮，始终可见，点击切换到设置页。能力面板与设置页互斥：进入设置页时能力面板隐藏，返回工作台时恢复上次激活的能力面板。

### 1.3 中央 Workbench

占比 70%，是唯一主舞台。顶部是 Sheet/Tab 标签栏，下方是 antd Table。

v1.0.0 无数据时显示 Empty 占位（「点击工具栏「导入」或拖拽文件到此处开始」）。

### 1.4 右侧 AI 面板

固定宽度（约 280px），v1.0.0 显示：

- 顶部标题「AI 助手」
- 中央 Empty 占位（「AI 能力 v1.1+」+ 描述文案）
- 底部折叠的「IPC 契约」信息（`ai_suggest` / `invoke_ai_op` 已就绪，返回 `unimplemented`）

## 2. Sheet/Tab 多页交互

| 操作 | 交互 |
|---|---|
| 新建 Sheet | 导入文件时自动创建；Tab 标题默认源文件名（去扩展名） |
| 切换 Sheet | 点击 Tab 标题切换 activeSheet；Table 内容切换；选区/列序各自独立 |
| 关闭 Sheet | Tab 右侧 × 按钮；关闭前确认「关闭后 Sheet 数据从内存移除（SQLite 仍保留）」 |
| 重命名 Sheet | 双击 Tab 标题进入编辑态；回车确认；空值回退原名 |

Sheet 状态独立：每个 Sheet 维护自己的 `headers` / `rows` / `selection` / `columnOrder` / `columnVisibility`。

## 3. antd Table 交互

### 3.1 选区框选

- 鼠标在 Table body 拖拽框选矩形区域（行×列）
- 选中 cell 蓝色高亮边框
- `Ctrl` / `Cmd` + 点击追加单 cell 到选区
- 选区信息显示在 Table 上方状态条（「已选 N 行 × M 列」）

### 3.2 列 checkbox 选

- 表头每列有 checkbox
- 勾选列 → 整列高亮（淡蓝背景）
- 表头全选 checkbox → 全选/全不选
- 列勾选状态影响后续列操作（重命名/删除/恢复列序）的作用范围

### 3.3 列拖拽排序

- 拖拽表头列标题左右移动调整列顺序
- 列顺序持久化到 SQLite `sheets.column_order`（JSON 数组）
- 列序与列 checkbox 选独立：拖拽不改勾选状态

### 3.4 状态高亮

v1.1.0 已落地 4 种行状态着色（`DataTable.css` 实际值）：

| 状态 | 着色 | 触发能力 |
|---|---|---|
| default | 透明 | 默认 |
| invalid | 浅红底 `#fff1f0` | 校验不通过 |
| masked | 浅蓝底 `#f0f5ff` | 已脱敏 |
| hit | 浅绿底 `#f6ffed` | 提取命中 |

v1.0.0 仅 `default`；v1.1.0 起脱敏/校验/提取能力触发对应着色。

## 4. 导入流

主流程（v1.0.0 核心闭环）：

1. 用户点工具栏「导入」或拖拽文件到 Workbench
2. 系统文件对话框（CSV/XLSX 过滤）→ 选定路径
3. Tauri 调 `import_file(path)` → core 识别类型 → 读 records → 写 SQLite（session + sheet + cells + operation 日志）→ 返回 sheet_id
4. 前端新建 Sheet Tab → 调 `get_sheet_data(sheet_id)` 拉首屏 50 行 → 渲染 antd Table
5. 状态条显示「源文件名 / 类型 / 总行数 / 导入时间」

异常：
- 文件格式不支持 → `message.error("不支持的文件格式")`，不新建 Sheet
- 解析失败 → `message.error("解析失败：<详情>")`，不新建 Sheet
- DB 写入失败 → `message.error("数据库写入失败：<详情>")`，不新建 Sheet

## 5. 状态

| 状态 | 表现 |
|---|---|
| 空状态 | Workbench 中央 Empty（「点击工具栏「导入」或拖拽文件到此处开始」） |
| 加载 | 导入中 Spin 覆盖 Workbench |
| 错误 | `message.error` Toast + 不阻塞其他 Sheet |
| 已保存 | 所有改动自动写 SQLite，无需手动保存（无「未保存」状态） |

## 6. 设置页

点击左侧能力面板底部「⚙ 设置」→ Workbench 区域被设置页覆盖（Sheet/Tab 暂存内存不丢）：

| 区块 | v1.0.0 内容 |
|---|---|
| 应用更新 | 当前版本号 + 「检查更新」按钮（触发 Tauri updater）+ 上次检查时间 |
| tshark 路径 | 路径输入框 + 「自动检测」按钮 + 「选择文件」按钮（v1.3+ PCAP 能力预留，v1.0.0 仅 UI，不持久化逻辑可选） |
| 数据库 | SQLite 文件路径（只读显示 `app_config_dir/ruT0datakit.db`）+ 「打开所在目录」按钮 |
| 关于 | 项目名 / 版本 / License / 仓库链接 |

设置页返回：左上角「← 返回工作台」按钮回到 Workbench，同时恢复上次激活的能力面板（若有）。
